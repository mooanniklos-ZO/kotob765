# تطبيق كتاب: أثر الفكر الغربي المعاصر على المجتمع المسلم في الوقت الراهن
### إعداد وتأليف: الدكتور / مالك عبدالرحمن الرميمة (هاتف: 771134103)

---

## 🌟 نبذة عن التطبيق
تطبيق إسلامي فكري تفاعلي ثلاثي الأبعاد (3D) مبني بأحدث تقنيات **Android Jetpack Compose** و **Material Design 3**، يجسد البحث العلمي القيم للدكتور مالك الرميمة حول أثر الفكر الغربي وسبل التحصن الجذري للأمة الإسلامية.

---

## 🚀 المميزات الرئيسية
- 📖 **غلاف وتصفح ثلاثي الأبعاد (3D Interactive Book)**: محاكاة واقعية لتقليب صفحات الكتاب مع تأثيرات فيزيائية وظلال واقعية.
- 📜 **المحتوى الكامل لكتاب الأبواب الثلاثة**:
  - **المقدمة والتمهيد**: أهمية دراسة الفكر الغربي وحاجة الأمة للوعي.
  - **الباب الأول**: زمن بعثة الرسول الأكرم ﷺ ومراحل تأسيس الدولة الإسلامية (المرحلة المكية والمدنية، الوثيقة النبوية، وحلف الفضول).
  - **الباب الثاني**: التاريخ الإسلامي عبر العصور ومسيرة الخلافة الراشدة والأموية والعباسية والعثمانية وسقوط الأندلس.
  - **الباب الثالث**: الغزو الفكري المعاصر وأسبابه ووسائله مع الحل الجذري والتحصن الشامل.
- 🎓 **موسوعة وجدول المجددين في الإسلام**: توثيق شامل ومفهرس لـ 49+ مجدداً ومصلحاً عبر القرون الهجرية مع فلاتر البحث حسب القرن.
- 🛡️ **مصفوفة الغزو الفكري والتحصن الجذري**: دراسة مقارنة ومصفوفية بين وسائل الغزو، أسبابه، والحلول العملية.
- 🎧 **القارئ الصوتي الذكي (TTS)**: الاستماع الصوتي التفاعلي باللغة العربية مع التحكم بالسرعة (0.75x - 1.5x).
- 🔍 **محرك بحث فوري فائق السرعة**: للبحث في نصوص الكتاب بالكامل والانتقال المباشر.
- 🔖 **نظام الإشارات المرجعية وتدوين الملاحظات**: حفظ المقاطع المهمة وإضافة تأملات القارئ.
- 🎨 **أنماط قراءة متعددة**: ورق كلاسيكي فاخر، سيبيا دافئ للعين، ووضع ليلي زمردي، مع تكبير وتصغير الخط.
- 🎯 **اختبار تفاعلي للمعلومات**: أسئلة قياس استيعاب مع نتائج وتوضيحات تفصيلية من نصوص الكتاب.

## 📲 كيفية تحميل وتثبيت ملف الـ APK على هاتفك الأندرويد

### الطريقة الأولى (عبر GitHub Releases - الأسهل والأسرع):
1. ادخل إلى صفحة مستودعك في GitHub: `https://github.com/mooanniklos-ZO/kotob765/releases`
2. اضغط على الإصدار **v1.0.0**
3. حمل ملف: `Athar-AlFikr-AlGharbi-v1.0.apk`
4. افتح الملف في هاتفك واضغط **تثبيت (Install)**.

### الطريقة الثانية (عبر GitHub Actions Artifacts):
1. افتح تبويب **Actions** في مستودع GitHub: `https://github.com/mooanniklos-ZO/kotob765/actions`
2. اضغط على أحدث تشغيل (Build Android APK / Assemble & Release APK) بعد إتمامه باللون الأخضر.
3. في أسفل الصفحة عند قسم **Artifacts**، ستجد ملف **Athar-AlFikr-AlGharbi-APK** جاهزاً للتحميل المباشر.

---

## 🛠️ البناء اليدوي المحلي (Local Build)
```bash
./gradlew assembleDebug
```
ملف الـ APK الناتج:
`app/build/outputs/apk/debug/app-debug.apk`
